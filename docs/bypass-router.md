# 旁路由检查与监控

共享实现由 upstream.lock 锁定到 Clash-Manager 的正式提交。页面已调整为只读检查与监控：展示 TUN 配置/运行态、DNS 配置、系统 IPv4 转发、防火墙摘要和局域网来源的活动连接，并提供设备接入指引。

不再提供“开启旁路由”、自动配置转发/NAT、自动恢复或设备出口编辑。原有 TUN/DNS 控制入口保留。

1.6.4 FPK 包含只读监控页、邻居设备发现及设备诊断/日志。设备详情展示当前连接的目标、入站、规则和出口；可按可识别的源 IP 筛选保留日志，或切换全局日志，并支持暂停、警告/错误筛选、复制及导出。

设备发现不代表在线或已接管，命中代理出口不代表访问成功，没有匹配日志不代表没有故障。系统转发或防火墙处丢包可能不进入 Mihomo，必要时仍需抓包。

页面读到的配置或规则不代表真实 fnOS 客户端已接管，仍需设备流量和真机证据。

1.6.3 默认隐藏标准 Docker 内部网桥设备，并提供“显示容器网络”开关。局域网 TUN 摘要及接入网卡也排除这些网桥，不按 172 地址段排除设备。非标准自定义 Docker 网桥名暂不自动识别。

1.6.4 精简设备列表并保留当前连接的上传/下载累计流量。详情改为弹窗，顶部保留 MAC、网卡及最近观察；移除重复汇总，诊断说明默认折叠，并加高日志区域。日志仍复用全局 Controller 保留日志，按可识别的源 IP 筛选，未改变保存策略。
