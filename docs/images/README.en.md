These images accompany the [Chinese user guide](../user-guide.md), captured on 2026-10-07.

- UI: actual Clash for fnos v1.3.0 frontend, operated and captured in a browser.
- Data: fictional profiles, proxies, rules and status in a local demo environment; no real subscriptions or devices.
- `example.com`, `example.org`, `demo-password`, `ui-fixture` and `198.51.100.20` are demonstration values, not usable proxy configurations.
- Screenshots illustrate navigation and operations; they do not prove installation or traffic routing on real fnOS.
- Theme: dark. The real application follows fnOS and can display a light theme.
